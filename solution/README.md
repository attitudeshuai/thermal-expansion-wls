# 难点与测试对应

## 难点 1：异方差必须加权

推理轴：领域公式

落在推理路径上的哪里：每个采样点自带不确定度 sigma，升温越高噪声越大。权重取 1/sigma² 才是最大似然，等权处理会把高噪声段（高温端）和低噪声段同等对待，参数的**标准误**直接差出好几倍，`chi2_red` 也从 1 附近跑到别的量级。原实现连 sigma 都没读。

对应测试：test_std_errors_reflect_point_weights、test_chi2_reduced_near_unity

## 难点 2：参数协方差的自由度与矩阵

推理轴：数值方法

落在推理路径上的哪里：标准误来自 `sigma_hat²·(XᵀWX)⁻¹`，其中 `sigma_hat² = 加权残差平方和 /(n - 3)`（自由度是 n 减参数个数，不是 n）。少了这一步，标准误整体偏小约根号下 n/(n-3) 的比例；漏掉矩阵求逆的尺度也会让相关系数算错。原实现根本没有这几栏。

对应测试：test_coefficients_match_independent_wls、test_corr_a1_a2_matches_independent、test_report_schema_and_rounding

## 难点 3：恒温保持段只留一个点

推理轴：数据口径

落在推理路径上的哪里：控温平台有 40 个重复温度点，它们不带来新的温度信息，却把权重全部堆在同一个温度上，等于人为放大该点的权重。规则是每组连续保持点只保留第一个。原实现把这些点全算进去了，`n_used` 和系数都会偏。

对应测试：test_plateau_run_kept_once_only、test_second_dataset_with_other_range

## 跨运行状态（重复运行与不污染）

同一份记录重复运行，报告逐字节一致（不能写时间戳）；运行失败时不能覆盖上一次的报告：先写临时文件再原子替换，非法记录以退出码 2 收场且不落文件。对应测试：test_rerun_produces_identical_bytes、test_failed_run_keeps_previous_report。

非法输入另有 test_invalid_data_rejected_without_output 单独覆盖（sigma 非正、点太少、没有温度跨度、剔除后有效点不足）。

## 权重口径

10 条测试：系数 0.16、标准误 0.15、恒温段剔除 0.11、第二套数据 0.12、卡方 0.09、相关系数 0.09、非法记录 0.11、输出契约 0.07、重复运行 0.05、失败不覆盖 0.05，和为 1。

## 定标依据（自检用）

判分侧独立按加权最小二乘复算（自己的 3×3 求解与求逆代码），与参考解在系数上一致到 1e-9、标准误与相关系数一致到 1e-12。噪声按 std 恰好等于 sigma 生成，所以出厂记录的 `chi2_red` 落在 1 附近（实测 1.034）。本地实测参考解 1.000000、缺陷版 0.000000；缺陷版是等权拟合、把恒温段全算进去、报告只有系数加运行时间戳，10 条全挂。
